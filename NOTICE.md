# Notice

Mirqab is an educational cyber range. The liquefaction plant it models is fictional and composite.
It is not any real facility, it carries no operational parameters from any real plant and it must not
be used to operate, harm or interfere with any industrial system. Use it to learn defensive
engineering only.

## References

Mirqab is built on public, authoritative material. The text in this project is original and bilingual.

- National Cyber Security Agency of Qatar, National Information Assurance and incident material
- NIST SP 800-82 Guide to Operational Technology Security
- NIST SP 800-61 Computer Security Incident Handling Guide
- ISA and IEC 62443 series for industrial automation and control systems security
- MITRE ATT&CK for ICS
